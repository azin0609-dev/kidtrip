## A. 從 3–6 歲孩子爸媽的角度：還缺什麼

依「每週實際會不會用到」排序。

### 第一優先：出門前最常卡住的事

1. **設施細節標籤**（資料欄位擴充）
   - 哺乳室／尿布台、親子廁所、推車可借、停車難易、有沒有餐廳或可帶外食、遮蔭多寡。
   - 篩選加開關：「有哺乳室」「好停車」「可以帶便當」。
   - 這是爸媽到現場最常踩雷的地方，比票價更重要。

2. **適合年齡**
   - 每個景點標「最適合幾歲」（例如 2–6 歲、4 歲以上）。
   - 搭配設定裡的孩子出生年月，自動提示「核桃還太小，有些設施不能玩」。
   - KidZania 這類「3 歲能玩的不多」的景點最需要。

3. **建議停留時間＋午睡友善行程**（PRD 2-3）
   - 每個景點加「建議待多久」（1 小時／半天／一整天）。
   - 依車程和午睡時段算：「9:30 出發，12:30 上車回家，車上剛好睡」。
   - 單程超過 90 分鐘自動建議「住一晚」並帶出附近飯店。

4. **雨天備案自動配對**
   - 推薦戶外景點時，同一張卡附上「下雨的話改去：XX（車程 10 分）」。

### 第二優先：讓 App 越用越懂你們家

5. **去過後的快速評分**（PRD 2-5）
   - 1–5 顆星＋快速標籤：「會再來」「小孩超愛」「人太多」「推車難推」。
   - 評分回饋推薦：愛恐龍館的家庭多推博物館類。

6. **集章護照**（PRD 2-4）
   - 每去一個地方蓋一個恐龍章，給小孩看的大圖模式。
   - 北中南東各一頁，集滿一區有小恐龍動畫。這是讓小孩主動說「我們這週去哪」的動力。

7. **出門清單**
   - 依景點類型自動產生：玩水 → 泳衣、毛巾、替換衣物；農場 → 防蚊液、帽子；冬天山上 → 外套。
   - 可勾選，存在本機。

### 第三優先：家庭之間

8. **家庭同步**（PRD 2-1，需要 Supabase）
   - 現在的分享連結是單次合併，真正同步要帳號。等用一個月確定有需要再做。

9. **節慶活動**
   - 每季手動整理幾個限時活動（燈會、花季、夏日戲水），用現有的 `opens_on`／`closes_on` 就能處理。

### 星級評價（使用者希望參考 Google 評分並排除刷評）

**限制：** Google 規定除了 `place_id`，評分、評論都不能存進 JSON 或資料庫（PRD 第 8 節「已確認」）。也不能爬 Google 的評論，所以拿不到判斷刷評所需的逐則評論資料。

**可行做法（建議三層並用）：**

1. **即時查 Google 評分（PRD 3-1 提前做）**
   - 使用者點開卡片時，透過 Edge Function 用 Places API 查「評分＋評論數」，只顯示不儲存。
   - 需要 Google Cloud 帳號、綁信用卡、API 金鑰放伺服器端；要設每月費用上限。
   - **降低刷評影響**：用評論數加權（貝氏平均）。評論很少的 5.0 分會被拉向平均值，例如 12 則 5.0 分會排在 3,000 則 4.6 分後面。這是業界常見做法，能壓低少量灌水的影響，但無法真正辨識假評論，畫面要誠實寫「依 Google 評分與評論數換算」。
   - 評論數太少（例如少於 30 則）顯示「評論還不夠多」，不給星等。

2. **自家評分（PRD 2-5）**
   - 去過後打 1–5 星＋快速標籤，這才是最貼近 3–6 歲孩子家庭的評價，也不受刷評影響。

3. **編輯精選標記**
   - 整理資料時，被多個獨立來源推薦的地方標「多來源推薦」，不涉及 Google 資料。

### 親子餐廳（新資料類別）

- 新增 `data/restaurants.json`，跟景點、飯店同一套規則（id 發布後不能改、`needs_verify`、不存 Google 評分）。
- 欄位草案：`id`（`food-001`）、name、city、region、`price_tier`、`tags`（`play` 遊戲區、`kidchair` 兒童椅、`kidmenu` 兒童餐、`nursing` 哺乳室、`stroller` 推車可進、`parking` 好停車、`reserve` 建議訂位）、`cuisine`、tip、`near_spot_ids`、lat、lng、`google_place_id`。
- 畫面：
  - 景點卡加「附近吃飯」，列 1–2 間（像飯店卡的「順遊」）。
  - 新分頁或篩選「親子餐廳」，可依車程、遊戲區、兒童椅篩選。
  - 推薦的三個景點，可順便帶出午餐建議，配合午睡時間。
- 初版建議先整理北部 30–50 間（你們最常去的範圍），用跟飯店一樣的多來源取樣。

## B. 新增「出國玩」：日本親子自由行

### 定位

台灣版是「這週末去哪」，日本版是「一年一兩次的大旅行」，用法不同：

- 不需要每週推薦、車程排序。
- 需要的是**幾套現成的行程骨架**，每天 2–3 個點，留很多休息時間。
- 資料量小（每套行程 5–7 天 × 2–3 個點），手動整理就好。

### 畫面

- 新增第四個分頁「出國玩」，或首頁一個入口卡片。
- 第一層：行程卡片（北海道 7 日、東京 5 日、大阪 5 日…），顯示天數、適合季節、適合年齡、預算級距。
- 第二層：逐日行程。每天一張卡：去哪、為什麼適合小小孩、交通方式、注意事項（要預約、身高限制）。
- 每個點一樣有 Google Maps 連結。
- 共用現有功能：收藏、恐龍風格。

### 資料結構（草案）

```
data/trips/hokkaido-7d.json
{
  "id": "trip-hokkaido-7d",
  "title": "北海道親子七日遊",
  "region": "北海道",
  "days": 7,
  "best_seasons": ["夏", "冬"],
  "age_hint": "3 歲以上",
  "budget_tier": "$$$",
  "base_cities": ["札幌", "小樽"],
  "tips": ["冬天路面結冰，推車很難推，建議揹巾", "..."],
  "itinerary": [
    { "day": 1, "title": "抵達札幌", "stops": [
        { "name": "...", "type": "park", "tip": "...", "booking": false }
    ], "stay": "札幌" }
  ],
  "needs_verify": ["..."],
  "last_verified": "YYYY-MM-DD"
}
```

### 三套行程的大方向（景點都要開工前再查證營業與預約規定）

**北海道親子七日遊**（夏天 7–8 月或冬天 12–2 月）
- 第 1–2 天 札幌：大通公園、圓山動物園；冬天看雪祭（2 月初）或去室內樂園。
- 第 3 天 小樽：運河散步、音樂盒堂，當天來回。
- 第 4–5 天 旭川／美瑛：旭山動物園（企鵝散步是冬季限定）；夏天加富良野花田。
- 第 6 天 登別或定山溪：溫泉飯店休息一天，登別有熊牧場、尼克斯海洋公園。
- 第 7 天 新千歲機場：機場裡有哆啦 A 夢空中樂園，可以放電到登機。
- 重點：移動距離長，建議租車；冬天要準備兒童雪衣。

**東京親子五日遊**
- 第 1 天 上野：上野動物園＋國立科學博物館，同一區不用換車。
- 第 2 天 東京迪士尼樂園或海洋（小小孩先選樂園）。
- 第 3 天 台場：teamLab、樂高樂園探索中心、海濱公園玩沙。
- 第 4 天 晴空塔＋淺草；或三鷹之森吉卜力美術館（要提早一個月以上預約）。
- 第 5 天 輕鬆逛街買東西後去機場。
- 重點：電車轉乘多、樓梯多，推車選輕便型；住在上野或東京站附近比較好移動。

**大阪親子五日遊**
- 第 1 天 大阪市區：海遊館＋天保山，水族館全室內，下雨也能去。
- 第 2 天 環球影城（任天堂世界、小小兵區適合小孩，熱門區要買快速通關或抽整理券）。
- 第 3 天 奈良：奈良公園餵鹿，當天來回。
- 第 4 天 天王寺動物園，或萬博紀念公園、NIFREL 生物館。
- 第 5 天 心齋橋、黑門市場逛完去機場。
- 重點：可以加一天京都，但寺廟多階梯，3 歲以下要評估。

### 之後可以再加

- 沖繩（自駕、海邊、美麗海水族館）、九州（福岡＋由布院）、名古屋（樂高樂園、吉卜力公園）。
- 每套行程的「雨天替代方案」。
- 簡單的預算估算（機票、住宿、門票級距）。

### 注意

- 日本景點的預約、身高限制、季節活動變動很多，資料要標 `needs_verify` 和整理日期，畫面標「以官方公告為準」。
- 不要抓 Google 或訂房網站的評分、照片（跟台灣版同一套規則）。
- 這會是 PRD 範圍外的新功能，建議開工前先寫進 PRD 當 Phase 1.5 或新的 Phase。

## E. 其他擴充面向

1. **大眾運輸可達性**：標「捷運／高鐵／台鐵站走路幾分鐘」。
2. **人潮與時段建議**：「假日 10 點前到比較好停車」「平日人少」。
3. **季節推薦**：花季、螢火蟲季、夏天玩水、冬天泡湯，依月份加分。
4. **三代同行模式**：少樓梯、有座位、不用走太遠的開關。
5. **成長回憶**：去過的地方記一句話或一張照片（只存手機，注意容量）。
6. **小孩投票模式**：推薦三個用大圖顯示，讓小孩自己選，搭配恐龍集章。
7. **年度回顧**：「今年去了 24 個地方、最愛動物園」。
8. **附近小兒科、急診**：健保署開放資料。
9. **花費紀錄**：門票、餐費，看每月出遊花多少。
10. **約朋友家庭**：會碰到帳號與社群，PRD 第 9 節目前不做。
11. **週四提醒推播**：符合使用情境，但 PRD 第 9 節目前排除，要使用者重新決定。
