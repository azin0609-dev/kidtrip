# 人工查證清單（2026-11-18）

給桌面版本機工作階段（Chrome＋Google 地圖、官網）用。查完直接改 `data/*.json`，跑 `npm run validate:data`。

## 規則
- 每一項都分「有、沒有、還不知道」（`yes`／`no`／`unknown`），不確定就留 `unknown`，不要猜。
- 查到的寫進 `amenities`（設施）和 `booking`（預約購票），`source` 寫來源（例如「官網」「Google 地圖」「電話」），`checked_at` 寫日期。
- 查證完把 `verified` 的日期和確認過的項目更新，`needs_verify` 拿掉查過的欄位。
- 來源互相矛盾：加 `risk_flags: ["status_conflict"]`，不要寫「還在營業」。
- 只能存 place_id、名稱、地址；Google 的評分、評論、照片不能存。

## 2. 最常被推薦的 30 個景點
依「從林口出發、單程 30–120 分鐘、晴天和雨天」模擬半年的推薦次數排序，再補上台北幾個熱門景點。

每個景點要查：
1. 正常營業時間、公休日、特殊休館
2. 要不要事先預約、事先買票、有沒有指定入場場次（`booking`）
3. 主要設施有沒有在維修（`amenities.maintenance_note`）
4. 停車場入口或精確位置（`amenities.parking_entrance`）
5. 尿布台、哺乳室、廁所（`diaper`、`nursing`、`toilet`）
6. 室內有沒有冷氣、戶外有沒有遮蔭（`aircon`、`shade`）
7. 推車通道、有沒有非走不可的樓梯（`stroller_path`、`stairs`）
8. 假日停車和人潮（`holiday_crowd`：low／medium／high／unknown）
